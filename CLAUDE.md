# test-website

## Project Overview
This is a beginner-friendly website project. All rules below must be followed exactly for every task.

---

## Project Structure

- Create exactly three files and nothing else: `index.html`, `styles.css`, `script.js`
- All three files must live in the same root project folder
- `index.html` is the main web page — all HTML structure goes here
- `styles.css` is the stylesheet — ALL styling goes here, never inline styles in HTML
- `script.js` is the JavaScript file — ALL JavaScript goes here, never in the HTML
- `index.html` must link to `styles.css` in the `<head>` section:
  ```html
  <link rel="stylesheet" href="styles.css">
  ```
- `index.html` must link to `script.js` just before the closing `</body>` tag:
  ```html
  <script src="script.js"></script>
  ```
- Never create additional CSS or JS files unless explicitly asked
- Images go in a folder called `/images/` inside the project root

---

## Code Style Rules

### HTML
- Use semantic HTML elements: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`
- Every image must have an `alt` attribute describing what it shows

### CSS
- The site must look good on both mobile phones and desktop (responsive design)
- Write clean, well-commented CSS — use comments to label each section
- Do not use any external CSS frameworks (no Bootstrap, no Tailwind)

### JavaScript
- Write clean, well-commented JavaScript — explain what each function does
- Do not use any JavaScript libraries unless specifically asked
